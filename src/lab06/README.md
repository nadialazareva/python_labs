# ЛР6 - CLI-утилиты с argparse (cat/grep-lite + конвертеры)

## Задание А: текстовые утилиты (`cli_text.py`)

### Что делает программа:
Утилиты:
1. cli_text
    - stats
    --input, --top (считает слова, выводит Топ-N)
    - cat
    --input, -n (выводит файл построчно, `-n` нумерует строки)
2. cli_convert
    - json2csv
    --in, --out (JSON -> CSV)
    - csv2json
    --in, --out (CSV -> JSON)
    - csv2xlsx
    --in, --out (SCV -> XLSX)
